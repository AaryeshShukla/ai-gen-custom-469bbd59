# Movie Quiz App

## Overview
This is a fully interactive movie quiz application where users can test their knowledge of movies. The app features a scoring system, progress tracking, and sound feedback for correct and incorrect answers.

## Features
- Multiple-choice questions about movies
- Scoring system that tracks correct answers
- Visual progress bar indicating quiz progress
- Sound feedback using Web Audio API for correct and incorrect answers
- Local storage to save high scores
- Restart button to retake the quiz

## Technologies Used
- HTML
- CSS
- JavaScript
- Web Audio API

## Setup Instructions
1. Clone the repository or download the files.
2. Open `index.html` in your web browser.
3. Enjoy the quiz and test your movie knowledge!
